# THE LOVE TIMES — сайт-подарок

## Как открыть
Откройте `index.html` в браузере (нужен интернет — для шрифтов Google Fonts).

## Что менять
**Всё — в одном файле `js/config.js`.** Открывайте его любым текстовым редактором.
- **Имена, дата, выпуск** — `herName`, `yourName`, `date`, `issueNumber`.
- **Тексты** — строки в кавычках. Абзацы истории — это списки `[ "..." , "..." ]`; чтобы добавить абзац, добавьте строку через запятую.
- **Фото** — положите файлы в папку `images/` и впишите имя в `src` / `image` / `coverImage`. Пока файла нет, на его месте показывается заглушка.
- **Цвета** — блок `colors` (меняйте оттенки фиолетового).
- **Галерея** — у каждого фото своя `category`; кнопки фильтра создаются автоматически.
- **25 причин** — добавляйте строки в списки `reasons`; номера считаются сами.
- **Хроника, цитаты** — добавляйте объекты `{ ... },` в списки.

## Файлы
- `*.html` — 7 страниц-оболочек, содержимое рисуется скриптом.
- `css/style.css` — оформление. `js/script.js` — отрисовка и эффекты.

Совет: фото лучше сжать до 200–500 КБ, чтобы сайт открывался быстро.

## Дополнительно
- **Счётчик «Мы вместе уже»** (главная): дата в `together.since`, формат `2023-03-12T18:00:00`. Чтобы убрать, удалите блок `together`.
- **Созвездие** (`constellation.html`): звёзды в `constellation` сами выстраиваются в сердце, по нажатию показывают воспоминание. Лучше 8–14 звёзд.
- **Анимации** лежат в конце `css/style.css`. Если у человека включено «уменьшить движение» в системе, они отключаются сами.
